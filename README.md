## How it works

1. In TikTok, tap **Share → Copy link** on a public post.
2. Paste the link on [toltik.com](https://toltik.com/) and press **Download**.
3. Pick the file: MP4 without watermark, HD MP4, the sound, or each photo.

Accepted links: `www.tiktok.com/@user/video/ID`, `/photo/ID`, `m.tiktok.com`, and the short links `vm.tiktok.com` / `vt.tiktok.com`.

## What it cannot do

- Private, deleted or region-blocked posts.
- Expired stories (stories last 24 hours).
- Download links expire after 1 hour — paste the TikTok link again.
